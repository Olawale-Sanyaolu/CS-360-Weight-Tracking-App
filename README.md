# CS 360 – Weight-Tracking App

Developer: Olawale Sanyaolu
Course: CS 360 – Mobile Architecture and Programming
Project: Weight-Tracking Mobile Application

## 1. App Requirements and User Needs

The goal of my Weight-Tracking App was to help users record their daily weight, establish personal weight goals, and monitor their progress. The application was designed to provide a simple, organized, and convenient way for individuals to manage their weight information.

The project requirements included user registration and login, daily weight entries, weight history, goal setting, and SMS notification functionality. I developed the application using Java, Android Studio, and SQLite.

## 2. User-Centered UI Design

I designed several screens to support user needs, including login, registration, a home dashboard, weight entry, goal setting, and SMS notification settings.

My design focused on simplicity, consistency, and ease of navigation. I used clearly labeled buttons, organized input fields, and straightforward layouts to help users interact with the application.

The dashboard was particularly important because it provided convenient access to weight records and other application features. Designing the interface before implementing the functionality helped me create a more organized and user-friendly application.

## 3. Coding Approach and Development Strategies

I approached the development process by dividing the application into smaller components. I began by designing the user interface in Project Two and then worked on implementing functionality in Project Three.

I used Java to manage application behavior and SQLite to store and retrieve user information and weight records. I also implemented input validation, event listeners, and database helper methods.

One important lesson I learned was the value of incremental development. Building and testing features individually helped me identify errors and understand how different components worked together. I plan to apply this approach to future software development projects.

## 4. Testing and Functionality

I tested my application using the Android Studio emulator. I examined screen navigation, button interactions, account registration, login functionality, weight entry, and database operations.

During testing, I encountered challenges with deleting weight records and displaying weight history correctly. These issues helped me understand the importance of debugging and repeatedly testing application features.

I learned that successfully compiling an application does not necessarily mean every feature works correctly. Testing is essential for identifying errors, improving reliability, and ensuring that the application meets user expectations.

## 5. Innovation and Overcoming Challenges

One of my biggest challenges was connecting the SQLite database to the application's user interface. Some features initially displayed correctly but did not perform their intended actions.

For example, I encountered difficulties implementing the delete functionality and updating weight history. I addressed these challenges by reviewing my Java methods, examining event listeners, adjusting database operations, and testing the application repeatedly.

This experience improved my problem-solving abilities and taught me to troubleshoot issues systematically.

## 6. Demonstrating My Skills and Experience

I am particularly proud of my work developing the SQLite database helper and connecting database operations to the Weight-Tracking App.

This component allowed me to apply my knowledge of Java programming, database management, input validation, and mobile application development.

The project also strengthened my understanding of Android Studio, interface design, application navigation, and debugging techniques.

Final Reflection

Completing this project significantly improved my understanding of the mobile application development lifecycle. Before taking CS 360, I mainly focused on writing code and making applications function.

Through this course, I learned that successful application development requires understanding user needs, planning effective interfaces, implementing functionality, and conducting thorough testing.

Although I encountered technical challenges, these experiences strengthened my programming, debugging, and problem-solving skills. I plan to apply these lessons to future software development projects as I continue pursuing my career in computer science.
